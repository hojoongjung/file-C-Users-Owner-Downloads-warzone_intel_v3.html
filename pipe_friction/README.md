# 관로마찰 실험 (실험 5)

드론 프로젝트와 무관한 별도 과제다. 2026-10-13 받은 스캔본(교재 「기계공학실험」 실험 5 p.68~75 + KSNU Wave Engineering Laboratory 실험 슬라이드 3~25쪽)을 옮겨 적었다. 1회차 측정값은 아래 '측정 기록'에 있다.

## 실험 목적

1. 관로의 주손실(관 벽 마찰)과 부차적 손실(급확대·급축소, 곡관, 밸브 등)을 관찰하고, 유량에 따른 수두손실을 측정해 다르시 마찰계수 f와 손실계수 K를 구한다.
2. 벤투리관, 오리피스관(교재는 노즐 포함) 유량 측정에서 수두차로 유량계수(송출계수) C를 구하고 서로 비교한다.
3. 급확대관, 급축소관에서 수두차로 손실계수 K(또는 마찰계수 f)를 구한다.

## 이번 실험 장치 (슬라이드 '파이프 직경' 표)

| 구분 | D1 [mm] | D2 [mm] | 비고 |
| --- | --- | --- | --- |
| 급확대관 | 25 | 40 | |
| 급축소관 | 40 | 25 | |
| 오리피스관 | 25 | 20 | β = d/D = 0.8 |
| 벤투리관 | 32 | 20 | β = 0.625 |
| 직관 | ? | | 안지름과 압력 탭 간격 L 미정 |

- 다관 마노미터(물기둥)로 압력 탭 사이 수두차 Δh를 읽는다. Δp = γΔh.
- 유량은 면적식 유량계(로터미터)에서 읽는다. 튜브 안 부표의 평평한 면이 가리키는 눈금을 읽는다. 슬라이드 사진은 약 3000 L/h.
  - 유량계에는 눈금이 두 줄 있다. 600~5000 L/h 눈금과 10~80 눈금이다. 슬라이드 사진에서 10은 600 L/h, 50은 3000 L/h와 같은 높이라 10~80 눈금은 L/min이다(L/h = 60 × 이 눈금).
- 그 밖의 장치: 저수조(Low tank), 펌프, 전원 스위치.
- 교재 표 5-1(오리피스 22.2/10.0, 벤투리관 37.7/18.85, 노즐 28.4/12.0, 급확대·축소관 37.7/18.85)과 교재 그림 속 치수(벤투리 37/18.5, 노즐 28.4/12.7, 오리피스 23/14.55)는 다른 장치 값이라 계산에 쓰지 않는다.

## 실험 방법

1. 저수조에 물을 약 2/3(교재는 4/5) 채우고 밸브를 모두 연다.
2. 펌프 전원을 켠다.
3. 온도계로 물 온도를 잰다(밀도·점성계수 계산에 씀).
4. 측정할 관로의 밸브와 유량조절 밸브만 열고 나머지 밸브는 모두 잠근다.
5. 물을 충분히 순환시켜 관로 안 기포를 빼고, 다관 마노미터 안 공기도 완전히 뺀다.
6. 유량조절 밸브로 유량을 바꿔 가며(교재: 5차례) 요소 양단 탭의 마노미터 높이를 읽는다. 수두가 안정된 뒤 읽고, 마노미터 안에 기포가 생기지 않게 한다.
7. 급확대관, 급축소관, 오리피스관, 벤투리관 4개를 측정해 수두차를 기록한다.
8. 끝나면 전원을 끄고 저수조와 모든 라인을 청소한다.

주의사항(교재)

- 다관 마노미터는 유리관이라 조심해서 다룬다.
- 게이트 밸브 양단은 압력차가 커서 수은 U자 마노미터로 잰다. 수은주 차가 범위를 넘어 수은이 관로로 넘어가지 않게 한다. 수은-물 마노미터라면 물기둥으로 바꿀 때 Δh_물 = (13.6 − 1) × Δh_수은.
- 다른 관로를 실험할 때는 밸브 A를 완전히 열어 둔다.
- 유량은 적절한 범위 안에서 조절한다.

## 측정할 때 함께 적을 것

- 물 온도 [°C]
- 요소마다 유량 Q [L/h]
- 상류 탭 높이 h1, 하류 탭 높이 h2 [mm]. Δh만 적으면 어느 쪽이 높았는지 사라진다. 급확대관은 하류 압력이 회복돼 하류 쪽이 더 높을 수도 있다.
- 직관을 측정하면 관 안지름과 탭 간격 L

## 공식

- 연속 방정식 (5.6): Q = A1V1 = A2V2, A = πD²/4
- 레이놀즈수 (5.2): Re = ρVD/μ = VD/ν
- 확장된 베르누이 식 (5.1): p1/γ + V1²/2g + z1 = p2/γ + V2²/2g + z2 + h_f + Σh_m
  - h_f: 관 벽 마찰에 의한 주손실, Σh_m: 각종 요인에 의한 부차적 손실
- 다르시-바이스바흐 식 (5.3): h_f = f · (L/D) · V²/2g → f = h_f · (D/L) · 2g/V²
  - 교재 식 (5.3)과 슬라이드에는 d/L로 인쇄돼 있지만 L/d가 맞다(오타).
  - f = g(Re, ε/D). 층류 f = 64/Re, 난류는 무디 차트(그림 5-1).
- 부차적 손실 (5.4): h_m = K · V²/2g → K = h_m · 2g/V²
  - K는 무차원수지만 Re나 조도비와의 관계는 고려되지 않고 실제 파이프 크기와 관련돼 나타낸다.
- 차압식 유량계 (베르누이 + 연속, 손실 없음 가정):
  - (5.5) p1/γ + V1²/2g = p2/γ + V2²/2g
  - (5.7) Q_이론 = A2 / √(1 − (A2/A1)²) · √(2g(p1 − p2)/γ) = A2 / √(1 − (A2/A1)²) · √(2gΔh)
  - (5.8) Q = C_d · Q_이론 → C = Q_측정 / Q_이론
- 베르누이 식 성립 조건: 비압축성, 비점성, 정상 상태, 하나의 유선, 유선상 총 에너지 일정, 외부와 에너지 교환 없음. 실제 물은 점성이 있고 열전달·내부에너지 변화가 있어 성립하지 않으므로 마찰 손실을 고려한다.

## 계산 방식과 이론값 (슬라이드 기준)

| 요소 | 기준 속도, Re | 측정값 | 이론값 |
| --- | --- | --- | --- |
| 급확대관 | 작은 관(25mm) 속도 | K = Δh · 2g/V² | K = (1 − d²/D²)² = 0.371 |
| 급축소관 | 작은 관(25mm) 속도 | K = Δh · 2g/V² | K ≈ 0.42(1 − d²/D²) = 0.256 (슬라이드 0.255) |
| 벤투리관 | 목(20mm) 속도 | C = Q/Q_이론 | C ≈ 0.9858 − 0.196β^4.5 = 0.962 |
| 오리피스관 | 목(20mm) 속도 | C = Q/Q_이론 | 그림 5-7 판독, 슬라이드 ≈ 0.625 (Re = 53020) |

- 교재 그림 5-3(벤투리): Re 10⁴~10⁸에서 C 0.94~0.99, 형상에 따라 범위가 있다.
- 교재 그림 5-5(노즐): β = 0.2~0.8, Re가 커질수록 C가 0.94~0.97에서 약 0.99로 올라간다.
- 교재 그림 5-7(오리피스, D·D/2 탭): β = 0.2~0.7, C 약 0.60~0.65. 이번 오리피스는 β = 0.8이라 그림 범위 밖이다.
- 계산 스크립트는 오리피스 이론값을 그림 5-7 곡선을 만든 ISO 5167 근사식(White, Fluid Mechanics, D·D/2 탭, Re는 관 기준)으로 구한다. 슬라이드 조건에서 0.621로 슬라이드 판독값 0.625와 비슷하다.
- 교재 참고: 유량계는 오리피스 → 노즐 → 벤투리관 순으로 만들기 어렵고, 오리피스는 압력손실이 매우 커서 압력강하가 문제 되지 않는 곳에만 쓴다. 적은 에너지로 보내야 하는 배관에는 압력강하가 가장 낮은 벤투리관이 좋다.

### 슬라이드 예시값 (20°C, ν = 1.00×10⁻⁶ m²/s, Q = 3000 L/h = 8.33×10⁻⁴ m³/s)

| 요소 | Δh [mm] | A [m²] | V [m/s] | Re | 슬라이드 결과 | 이론 |
| --- | --- | --- | --- | --- | --- | --- |
| 급확대관 | 170 | 4.91×10⁻⁴ | 1.696 | 42400 | K = 1.159 | 0.371 |
| 급축소관 | 440 | 4.91×10⁻⁴ | 1.696 | 42400 | K = 3.001 | 0.255 |
| 벤투리관 | 640 | A1 8.042×10⁻⁴, A2 3.141×10⁻⁴ | 2.652 | 53040 | Q_이론 1.209×10⁻³, C = 0.689 | 0.962 |
| 오리피스관 | 700 | 3.142×10⁻⁴ | 2.651 | 53020 | Q_이론 1.941×10⁻³, C = 0.429 | 0.625 |

- **슬라이드 오리피스 예시는 계산이 틀렸다.** Q_이론 1.941×10⁻³은 분모를 √(1 − A2/A1) = √(1 − 0.64) = 0.6으로 놓은 값이다. 식 (5.7)대로 √(1 − (A2/A1)²) = √(1 − 0.8⁴) = 0.768을 쓰면 Q_이론 = 1.515×10⁻³, C = 0.550이다. 벤투리관 예시는 식대로 맞게 계산돼 있다.
- `calc.py`로 이 예시를 다시 계산하면 급확대 1.157, 급축소 2.995, 벤투리 0.689가 나온다(슬라이드는 V를 1.696으로 반올림해서 조금 다름).

### 참고: 속도수두 보정

급확대·급축소관처럼 두 탭의 관 지름이 다르면 마노미터 Δh는 정압 차이일 뿐이고, 실제 손실수두는

h_L = (p1 − p2)/γ + (V1² − V2²)/2g

이다. 슬라이드 방식(K = Δh · 2g/V²)은 두 번째 항을 뺀 값이다. 그리고 두 탭 사이 직관 구간의 마찰 손실도 K에 섞여 들어간다. `calc.py`는 두 K를 모두 출력한다. 보고서에는 슬라이드 방식을 기본으로 쓰고, 이론값과 차이가 나는 이유로 이 두 가지를 쓸 수 있다.

마노미터 사진 3장(손글씨 표 순서로 보낸 것으로 가정) 판독값. 수면(메니스커스) 높이를 왼쪽 눈금으로 읽었고 오차는 ±3mm 정도다.

| 급확대관 | 651 | 427 | 224 |
| 급축소관 | 627 | 308 | 319 |
| 벤투리관 | 436 | 200 | 236 |

해석:

- **V값은 L/min이다.** 유량계의 10~80 눈금이다(위 '이번 실험 장치' 참고). 22.5, 31, 44 L/min → 1350, 1860, 2640 L/h.
- **왼쪽 관을 상류(h1)로 가정했다.** 벤투리관은 상류가 높아야 하는데 세 장 모두 왼쪽이 높다.
- **지름은 슬라이드 안지름(25→40, 40→25, 32→20)으로 계산했다.** 손글씨 값으로 계산하면 벤투리 C가 0.614로 벤투리관에서는 나올 수 없는 값(오리피스 수준)이 되고, 슬라이드 값이면 0.999가 된다. 32, 48, 26은 일반 PVC 관 25A, 40A, 20A의 바깥지름과 같아서, 손글씨 지름은 관을 바깥에서 잰 값으로 보인다. 확인 전까지는 계산에 쓰지 않는다.
- 물 온도를 모르므로 20°C로 계산했다.

검토:

- 벤투리관은 이론과 잘 맞는다. 손실이 없으면 Δh = (V2² − V1²)/2g = 235mm인데 236mm를 읽었다.
- **급확대관 Δh 224mm는 급확대만으로는 나올 수 없는 값이다.** 이 유량에서 손실이 없으면 하류가 25mm 높아야 하고(압력 회복), 이론 손실 11mm를 빼도 하류가 14mm 높아야 한다. 탭이 급확대 부분이 아닌 다른 구간(직관, 이음, 밸브)까지 걸쳐 있거나, 다른 관의 마노미터를 읽었을 수 있다.
- 급축소관 K도 이론의 약 20배다. 슬라이드 예시(K = 3.0)도 이론보다 훨씬 커서, 이 장치는 탭 사이에 다른 손실이 섞여 있는 것으로 보인다.

## 결과 정리 항목 (교재 7장)

1) 수두손실 측정: 관로 요소(직관, 곡관, 급확대관, 급축소관, 밸브, L자 이음)마다 유량 Q [m³/s]와 양단 액주계 높이차 [mm]

   1. 각 경우의 평균속도와 Re를 구한다(물 온도에 따른 밀도·점성계수는 참고문헌에서).
   2. 직관의 마찰계수 f를 구하고 무디 차트와 비교한다.
   3. 직관이 아닌 경우의 손실계수 K를 구하고 참고문헌 값과 비교한다.
   4. 각 구성요소에서 생기는 수두손실 크기를 비교한다.

2) 송출계수 측정: 오리피스, 노즐, 벤투리관마다 유량 Q [m³/s]와 양단 액주계 높이차 [mm]

   1. 각 경우의 평균속도와 Re를 구한다.
   2. Re에 따른 송출계수를 구하고 참고문헌 값과 비교한다.
   3. 각 유량계에서 생기는 수두손실 크기를 비교한다.

이번 실험은 슬라이드대로 급확대관·급축소관·오리피스관·벤투리관 4개다. 곡관, 밸브, L자 이음을 측정하면 K = Δh · 2g/V²로 같은 방식으로 구한다. 비교용 대략값(Çengel 유체역학 표): 90° 엘보 나사식 0.9, 플랜지식 0.3, 게이트 밸브 완전 개방 0.2, 글로브 밸브 완전 개방 10.

## 측정값 입력과 계산

1. `data.csv`에 측정 한 번을 한 줄로 적는다: `element,Q_Lph,Q_Lpm,D1_mm,D2_mm,h1_mm,h2_mm,dh_mm,note`
   - element: 급확대관, 급축소관, 오리피스관, 벤투리관, 직관
   - 유량은 Q_Lph(L/h)나 Q_Lpm(10~80 눈금, L/min) 중 하나만 적는다.
   - h1, h2를 따로 적거나 dh_mm(= h1 − h2, 상류 − 하류)만 적는다. 수두차가 아직 없으면 비워 둔다(유속과 Re만 나온다).
   - D1_mm, D2_mm(상류, 하류 안지름)을 비우면 슬라이드 안지름을 쓴다. 직관은 D1_mm = 안지름, D2_mm = 탭 간격 L.
2. 실행: `python3 calc.py data.csv --temp <물 온도>` (pipe_friction 폴더에서)
   - 물 밀도·점성계수는 온도로 보간한다(0~40°C). 슬라이드처럼 ν = 1.00×10⁻⁶을 쓰려면 `--nu 1.00e-6`.
3. 슬라이드 예시 검산: `python3 calc.py example_slide.csv --nu 1.00e-6`
